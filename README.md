# AI Claim-Source Attribution Research

Research design by Nazly Bim · Los Angeles

**Status:** Proposal and pilot design. No model runs or research findings are reported here yet.

## Research question

In synthetic multi-turn conversations, how accurately do AI models attribute claims to user statements, external records, or model inferences under delay, paraphrase, and correction? Can explicit source labels improve accuracy on held-out cases?

## Intended contribution

This project will develop reproducible evaluations of claim provenance in conversational AI, characterize failure patterns, and test a concrete intervention. It is oriented toward AI model evaluation and improvement. Behavioral results will not establish subjective awareness.

## Planned method

1. Write 24 fictional conversations with predetermined claim origins and matched experimental conditions.
2. Record model configurations, prompts, outputs, source labels, and supporting citations.
3. Measure accuracy and unsupported citations by condition; compare against transcript search.
4. Use baseline errors to design one provenance intervention, then evaluate it on held-out examples.
5. Release code, synthetic materials, and results after validation, subject to model terms.

See [proposal.md](proposal.md) for the detailed pilot protocol, preparation path, and application framing.
